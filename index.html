Want NeuroReader in every app?

Install the NeuroReader font on your computer. It applies a fixed version of the formula to anything you read, in any app, without opening this site.

Mac Windows Linux
How to install

Mac: double-click the downloaded file, then click “Install Font” in Font Book.

Windows: right-click the file and choose “Install”.

Linux: copy the file to ~/.local/share/fonts/, then run fc-cache -f.

Available variants: Regular, Variable, Italic, Bold-Italic, and Mono. Web developers: the font also ships as .woff2. Its word-start bolding uses OpenType contextual alternates (calt), which every browser applies by default — no CSS beyond the font-family needed. Source and rebuild instructions live in fonts/README.md.

Or install the extension

Transform any webpage automatically — install it and it just works, with no clicks needed. Works on Chrome, Edge, Brave, and Firefox. Same formula, same privacy — everything happens in your browser.
