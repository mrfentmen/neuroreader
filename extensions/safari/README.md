# NeuroReader — Safari extension source

Safari extensions can't be loaded unpacked like Chrome/Firefox ones. They
must be wrapped in a native app built with Xcode on a Mac:

```bash
xcrun safari-web-extension-converter extensions/safari
```

The converter generates an `.xcworkspace` with an app + extension target.
You then:

1. Open the workspace in Xcode, set your Team (requires a (free) Apple
   Developer account), and build.
2. Run the app once — Safari asks to enable the extension in
   Settings → Extensions.

Distribution to the App Store additionally requires notarization and a
paid Apple Developer account.

## Files

- `manifest.json` — the actual extension manifest (Safari 15+, which
  implements the WebExtension API). This is what the converter consumes.
- `Info.plist` — the extension target's Info.plist, generated by the
  converter; kept here as a reference.
- `formula.js`, `content.js`, `popup.html`, `popup.js`, `styles.css` —
  identical to the Chrome/Firefox builds. If you change the formula, change
  `index.html` too — they must stay in sync.
