# ClipForge Lockbox Chrome Web Store Listing

## Product name

ClipForge Lockbox — Private Image Vault

## Short description

Encrypt and store your own images locally in Chrome. No upload, sync, analytics, or password recovery service.

## Detailed description

ClipForge Lockbox is a clearly labeled local encrypted image vault for images you choose from your device.

Images are encrypted in Chrome with Web Crypto AES-GCM before ciphertext is stored in local IndexedDB. The password is never stored, and the extension has no server that can see or recover your files.

### Features

- Create and unlock a local vault with a password
- Import JPG, PNG, WebP, and GIF images
- Drag and drop support
- Encrypt images locally before saving
- Browse decrypted previews only while the vault is unlocked
- Delete encrypted records locally
- Lock the vault immediately
- No host permissions
- No content scripts
- No network access or analytics
- No remote executable code

### Important security limitations

ClipForge Lockbox is not “unhackable” and is not a replacement for a secure operating-system vault or password manager. There is no password reset or recovery service. Losing the password or clearing extension data can make images permanently inaccessible. It cannot protect against malware, keyloggers, screenshots, memory inspection, a compromised browser profile, or someone controlling the device while the vault is unlocked.

### Privacy

Images are processed and stored locally. ClipForge Lockbox does not upload, sync, analyze, sell, share, or collect images, filenames, image metadata, passwords, browsing activity, or analytics. The extension does not access webpages. It includes two static advertisement placeholders that load no ad code or tracking.
